# RIMU · 三个持续动态场景

## 公司内容

首页、客厅、餐厅保持原来的动态影像与切换。顶部导航以及客厅、餐厅的画面按钮可打开同一侧边信息层，包含公司简介、四项可咨询的结构工程服务、三张影像作品图。信息层打开时，背后的当前场景继续播放。联系方式沿用名片中的电话、Email、微信二维码，并在信息层底部提供统一入口。没有加入 WhatsApp 链接，因为现有资料未确认该号码是否开通 WhatsApp。

作品图从本项目三段视频提取，位于 `assets/work/`。网页明确写明它们是概念影像，并非已建成项目或客户案例照片；提供实际案例照片后，可替换图片和说明。四项服务以“可咨询方向”展示，具体工作范围由项目沟通确认，不虚构完成项目、年份或业绩。

`inspection/verify-business.cjs` 实测桌面与手机尺寸：三个信息标签、四项服务、三张图片、联系与名片入口均可操作；信息层打开 1.2 秒时，背景视频分别继续解码约 25～30 帧。截图和结果在 `inspection/business-browser/`。

运行 `npm start`，默认预览地址为 http://127.0.0.1:4173。也可通过 `PORT` 环境变量指定端口。网站没有前端运行依赖。

首页显示持续运动的完整住宅外景。点击画面或“点击进入住宅”，播放 `backgroundvideo-scrub.mp4` 中原有的推进镜头，进入客厅。滚轮、触屏上滑和方向键同样能切换。客厅转餐厅时，两个场景的视频同时播放，视角向右移动并经过一段短暂的室内遮挡；返回时方向相反。只有外景、客厅、餐厅三个停驻场景，没有可拖拽停驻的中间页。联系方式、名片和微信二维码仍在弹窗中。

| 场景 | 本次使用的原片 | 网页播放文件 | 源片规格 |
| --- | --- | --- | --- |
| 外景 | `视频生成与确认.mp4` | `assets/web/exterior-buffered-{840,1260}.mp4` | 1470×630，24fps，约 5.04 秒 |
| 客厅 | `生成山景客厅视频.mp4` | `assets/web/living-buffered-{840,1260}.mp4` | 1470×630，24fps，约 5.04 秒 |
| 餐厅 | `餐厅.mp4` | `assets/web/kitchen-buffered-{840,1260}.mp4` | 1470×630，24fps，约 5.04 秒 |

三段环境影像的水、雾、夕阳、火焰及窗外景色均来自原片。片尾和片头在输出时做短时正向融合，外景约 0.42 秒，客厅 0.50 秒，餐厅约 0.58 秒。外景和客厅采用新上传的稳定机位原片；旧外景循环所用的反向缩放、运动补帧已移除。每个文件在融合后附一秒保护画面，网页用两路解码器在同相位交接，避免浏览器单播放器回片头时停顿。交接时无需对可见视频执行 seek，也不冻结环境画面。

输出为 H.264、24fps、CRF15、yuv420p、faststart。Lanczos 生成 1960×840 与 2940×1260 两档；高像素密度桌面使用较大档，普通桌面与手机使用较小档。桌面保留完整 7:3 画幅，避免裁掉房屋和房间两侧。升采样改善浏览器放大时的显示效果，但原片的 1470×630 像素决定了真实细节上限。手机竖屏仍需要裁切才能铺满屏幕。页面没有模拟水波、雾或火焰的 CSS / WebGL 特效。

`inspection/prepare-buffered-loops.py` 可重建网页视频；具体参数见 `inspection/continuous-media-plan.json`。`?debug=1` 显示循环次数、播放时间和切换状态。`verify-continuous.cjs` 验证三场景播放、循环与切换；`inspection/verify-quality.cjs` 验证分辨率选择与首页连续解码。验证结果和画面保存在 `inspection/continuous-browser/`。浏览器模拟尺寸测试不能代表真实手机、Safari 或弱网条件。

本地复测：Edge / Chrome 桌面与 Edge 手机尺寸模拟各场景连续停留约 18.5 秒，所有场景各完成 4 次循环交接，可见 seek / ended 和页面脚本错误均为 0；手机尺寸的最终流程最大可见帧间隔约 67ms。高像素密度桌面实际加载 2940×1260 文件，普通桌面和手机加载 1960×840 文件。点击首页画面入屋、客厅与餐厅双视频同时播放的转向、反向返回及联系方式弹窗均已验证。

GitHub Pages 使用 `.github/workflows/pages.yml` 发布。`npm run build:pages` 只把网站运行所需的 17 个文件复制到 `dist-pages/`，不发布原始素材与检查文件。部署后访问 `https://kiwisitelab.github.io/scrollweb/`。
